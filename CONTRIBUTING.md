# Collaboration and permission requests

Collaboration, bug reports and suggestions are welcome. The original material identified in [LICENSE](LICENSE) is available for personal, noncommercial use, including local builds and private modifications. Reusing that material in another project, redistributing it or using it commercially requires prior written permission, subject to the exceptions in the license.

## Propose a collaboration

1. [Open a permission or collaboration request](https://github.com/dawoodtogoo2020-code/folklore-native-port/issues/new?title=Collaboration%20or%20permission%20request).
2. Describe your idea, the files or commit involved, and whether you intend to publish, redistribute or monetize anything.
3. Wait for explicit written agreement on the scope and contribution license before submitting code or distributing modifications. A request alone does not grant permission.

You retain ownership of your original contributions unless a separate agreement says otherwise. Do not submit code you cannot authorize for the agreed use. Existing third-party licenses continue to apply.

For ordinary bug reports or suggestions, no permission request is needed. Include reproducible steps and remove personal paths or sensitive information from logs.

## Private information and access

Public GitHub issues and source files are visible to everyone. Do not post credentials, personal information, game dumps, game assets, firmware, keys, generated game code or private project files. If your proposal needs private material, request a private contact route without attaching that material. Access and any confidentiality terms must be agreed separately.

## Runtime and third-party code

The public repository currently contains research tools, not the newer local runtime or a playable release. That local runtime includes GPL-covered code. The permission requirements for independently owned material do not override GPL rights, corresponding-source obligations or other third-party licenses. A future release needs a component-specific license review; this repository's custom license must not be applied to the entire runtime by default.

Public GitHub viewing and forking rights remain governed by [GitHub's Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service). Keeping source confidential requires private storage or a private repository with controlled access. A license alone cannot make public source private.
